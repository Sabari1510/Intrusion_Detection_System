About the Project

Project Overview

The Network Intrusion Detection System (NIDS) is a Machine Learning based cybersecurity application developed to detect malicious network traffic using supervised learning algorithms.

Dataset

CICIDS2017

The CICIDS2017 dataset contains both benign and malicious network traffic, representing modern cyber attacks such as DDoS, PortScan, DoS, Botnet, Web Attacks and many more.

Machine Learning Algorithms

  • Random Forest
  • Extra Trees Classifier
  • LightGBM
  • Stacking Ensemble Learning

Project Objectives

  • Detect malicious network traffic.
  • Improve cybersecurity using Machine Learning.
  • Compare multiple classification algorithms.
  • Provide real-time prediction support.
  • Visualize intrusion detection results.
